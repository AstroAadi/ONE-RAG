## 1. Lead-to-Client Onboarding Flow

This flow is designed to be a highly structured process that ensures a smooth and professional handover from the Sales team to the ongoing client management team.

## Detailed Step-by-Step Description:

|   Step | User Action    | Description                                                                                                                                                            | Primary Modules         |
|--------|----------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------|
|      1 | Sales Team     | A new lead is identified and entered into the system.                                                                                                                  | Master Data             |
|      2 | Sales Team     | Manages the lead through the sales pipeline using their dashboard. Triggers automated follow-up sequences.                                                             | Dashboard, Auto Comm    |
|      3 | Sales Team     | Generates a formal proposal and contract for the client.                                                                                                               | Doc Gen                 |
|      4 | Finance Team   | Once the client agrees, an invoice is raised. Finance receives the payment and updates the status to "Paid" in the system.                                             | Finance                 |
|      5 | System (Gated) | The "Paid" status acts as a trigger, automatically creating a "Complete Handover" task for the Salesperson.                                                            | Workflow/Task           |
|      6 | Sales Team     | Receives the task, uploads all final client documents, and selects an available Compliance Manager (CM) from a list to assign the client.                              | Doc Upload, Master Data |
|      7 | System         | Upon task completion, the client profile is fully activated. A welcome email with portal details is sent to the client, and a notification is sent to the assigned CM. | Auto Comm               |

## Potential Bottlenecks &amp; Dependencies:

- Process Bottleneck: The manual payment confirmation by the Finance Team (Step 4) is the biggest chokepoint. Any delay here halts the entire onboarding process.
- Resource Bottleneck: The availability of a Compliance Manager for assignment (Step 6). A high volume of new clients could lead to delays if all CMs are at capacity, impacting the client's first impression.
- Information Dependency: The quality of the handover depends on the diligence of the Sales Team in uploading all necessary documents. Missing documents can create immediate work for the new CM.

## 2. Core Service Delivery &amp; Filing Lifecycle (Manual Task Creation)

This is the central operational flow, now updated with the manual task creation logic. The CM acts as the control tower for all service delivery.

## Detailed Step-by-Step Description:

|   Step | User Action        | Description                                                                                                                                    | Primary Modules   |
|--------|--------------------|------------------------------------------------------------------------------------------------------------------------------------------------|-------------------|
|      1 | Compliance Manager | Reviews the client's service agreement and manually creates a new task (e.g., "File ITR for AY 2025-26").                                      | Workflow/Task     |
|      2 | Compliance Manager | Assigns the task to the appropriate operational team (e.g., Taxation Team ) and sets the priority.                                             | Workflow/Task     |
|      3 | System             | The task is created. It automatically populates the due date in the client's compliance calendar and appears on the Taxation Team's dashboard. | Dashboard         |
|      4 | System             | If documents are required, an automated notification is sent to the Client .                                                                   | Auto Comm         |
|      5 | Client             | Uploads the requested documents via the portal.                                                                                                | Doc Upload        |

|   6 | Operation Team   | Works on the task, updating its status (e.g., "In Progress," "Review Pending"). The CM can monitor this status in real-time.   | Workflow/Task, Dashboard   |
|-----|------------------|--------------------------------------------------------------------------------------------------------------------------------|----------------------------|
|   7 | Operation Team   | Completes the filing, uploads the acknowledgment, and marks the task "Completed."                                              | Doc Upload, Workflow/Task  |
|   8 | System           | The "Completed" status triggers a final confirmation email to the Client , with the CM automatically included in the CC.       | Auto Comm                  |

## Potential Bottlenecks &amp; Dependencies:

- Single Point of Failure: The Compliance Manager is the sole initiator of all work. If a CM is on leave, overloaded, or makes an error, service delivery for their clients will be delayed or missed. This is the most significant risk in this workflow.
- Scalability Issue: This manual creation process will become a major bottleneck as the client base grows. The CM's workload will increase linearly with the number of clients and services, making it difficult to scale.
- Communication Bottleneck: If the operational team requires clarification, they must go through the CM, who then contacts the client. This indirect communication can slow down resolution.

## 3. Grievance, Escalation &amp; Oversight Flow

This flow ensures that there are clear channels for support, executive oversight, and handling exceptional circumstances like an unavailable manager.

## Detailed Step-by-Step Description:

|      1 | Client             | Experiences an issue and contacts their Compliance Manager (CM) via email or phone.     | N/A               |
|      2 | Compliance Manager | Creates a "Grievance Ticket" (a task type) in the system, detailing the client's issue. | Workflow/Task     |

## Potential Bottlenecks &amp; Dependencies:

- Single Point of Failure (Support): As with service delivery, the CM is the single entry point for all support queries. This makes them a bottleneck and creates a risk if they are unavailable.
- Response Time Dependency: The effectiveness of the escalation path (Step 8) is entirely dependent on the System Admin's availability and defined response time.
- Investigation Overhead: The Executive oversight process (Steps 6-7) is streamlined but adds to the CM's workload, as they must investigate systemic issues in addition to managing client relationships and creating tasks.

## Detailed User Stories by Module

## Module 1- Document Upload Module

- As a Client, They want to:
- upload a single document to a specific folder (e.g., GST Returns), so that I can provide the necessary files for a filing.
- select and upload multiple documents at once, so that I can save time when providing a batch of files.
- view a list of all my uploaded documents with clear labels and dates, so that I can have a secure digital record of my filings.
- download any document I have previously uploaded or that the team has shared with me, so that I can access my records 24/7.
- As a Sales &amp; Onboarding Team member, They want to:
- upload the signed client contract and onboarding forms to the new client's profile, so that I can create a complete record for the handover to the Compliance Manager.
- As a Compliance Manager, They want to:
- review documents uploaded by a client, so that I can verify their completeness and accuracy before starting a task.
- upload a document on behalf of a client who has sent it via email, so that the central repository remains up-to-date.
- As a Compliance Operation team member,They want to:
- upload the final filed return and the government acknowledgment (challan/SRN), so that I can mark a task as complete and provide proof of filing.

## Module 2- Master Data Management Module

- As a Sales &amp; Onboarding Team member, They want to:
- create a new client profile with their name, business details, and contact information, so that they can initiate the onboarding process.
- As a Compliance Manager, They want to:
- view the complete master profile of my assigned clients, including all their compliance numbers (PAN, GSTIN, CIN), so that they have all necessary information in one place.
- edit a client's profile to add or update key contacts and DSC (Digital Signature Certificate) expiry dates, so that they can maintain accurate and current records.
- As a System Admin, They want to:
- manage the master list of services offered by the company, so that they can be correctly assigned to clients.
- define and update the compliance checklists and rules for different company types (Pvt Ltd, LLP, etc.), so that the system's logic remains current with regulations.

## Module 3- Finance Module

- As a Finance &amp; Renewal Team member,They want to:
- create a new invoice for a service rendered to a client, so that I can bill them accurately.
- view a dashboard of all outstanding invoices sorted by age, so that I can prioritize follow-ups.
- mark an invoice as "Partially Paid" or "Fully Paid" upon receiving payment, so that I can keep the financial records accurate and unlock gated workflows.
- As a Client, They want to:
- view a history of all my past and present invoices, so that I have a clear record of my expenses.
- download a PDF copy of any invoice, so that I can use it for my own accounting purposes.
- As a Sales &amp; Onboarding Team member, They want to:
- view the payment status of the initial onboarding invoice, so that I know when I can proceed with assigning the Compliance Manager.

## Module 4- Auto communication Module (Triggered based)

- As a Compliance Manager, They want to:
- send a message to a client using a pre-defined template, so that I can communicate quickly and consistently.
- view a chronological log of all automated and manual communications sent to a client, so that I have a complete history of our interactions.
- As a Finance &amp; Renewal Team member, They want to:
- trigger an automated payment reminder for an overdue invoice, so that I can improve the collection process.
- As a System Admin, They want to:
- create and edit the templates for all automated communications (e.g., welcome email, deadline reminders, invoice alerts), so that I can control the company's messaging.
- This module will be accessed by all the operation teams as well as the sales team for automated communication.

## Module 5- Auto Data Fetch and Fill Module.

- As a Sales &amp; Onboarding Team member,They want to:
- have the system automatically populate a client's name and contact details into a proposal template, so that I can generate proposals faster and with fewer errors.
- This would also be used by the compliance operation team to fill the templates based on clients requirements.

## Module 6- Template based Document Generation Module

- As a Sales &amp; Onboarding Team member, They want to:
- generate a standardized proposal PDF from a template by selecting a client, so that I can send professional documents quickly.
- As a Compliance Operation team member, They want to:
- generate a Board Resolution or a Share Certificate from a template for a specific client, so that I can fulfill compliance requirements efficiently.
- As an Audit Team member, They want to:
- generate a Net Worth Certificate using client data already in the system, so that I can provide certified documents without manual calculation.
- As a System Admin,  They want to:
- upload, manage, and version-control all the master document templates (e.g., .docx files), so that all generated documents are based on the latest approved format.

## Module 7- Dashboard Module

- As a Client, They want to:
- see my compliance calendar with color-coded dates (Red, Amber, Green), so that I can immediately understand my upcoming deadlines and obligations.
- view a list of all my active services with their current status (e.g., "Documents Received," "Processing," "Filed"), so that I have real-time visibility without needing to call or email.
- As a Sales &amp; Onboarding Team member, They want to:
- view my sales pipeline in a Kanban board format (New, Contacted, Proposal, Won), so that I can visually track and manage my leads.
- As a Compliance Manager, They want to:
- view a unified dashboard showing the status of all filings for all my assigned clients, so that I can proactively manage my portfolio and prevent delays.
- As a Taxation Team member, They want to:
- see a personalized queue of all tax-related tasks assigned to me, sorted by the nearest due date, so that I can prioritize my work effectively.
- As an Executive, They want to:
- view high-level KPIs on the main dashboard, such as Monthly Recurring Revenue (MRR), Client Churn Rate, and Overall Filing Compliance %, so that I can monitor the health of the business.

## Module 8- Workflow and Task Management Module

- As a Compliance Manager, They want to:
- manually create a task for a specific client service (e.g., "File AOC-4"), so that I can initiate the operational workflow.
- assign the created task to the correct operational team (e.g., Compliance Operation), so that the work is routed to the right people.
- create a "Grievance Ticket" for a client query and assign it to a department, so that I can formally track the resolution process.
- As a Compliance Operation team member, They want to:
- view a list of all tasks assigned to me in my personal queue, so that I know what I need to work on.
- update the status of a task from "Pending" to "In Progress" to "Completed", so that the system reflects the real-time status of my work.

## Module 9- Knowledge Base and AI Module

- As a Compliance Manager, They want to:
- search an internal knowledge base for Standard Operating Procedures (SOPs), so that I can quickly find answers to complex compliance questions.
- As a Client,  They want to:
- access a self-service FAQ section on the portal, so that I can resolve common queries instantly without needing to contact support.
- As a System Admin,  They want to:
- create, edit, and categorize articles in the knowledge base, so that I can maintain a repository of helpful and accurate information.

## Module 10- Security Management Module

- As a System Admin, They want to:
- create a new user account and assign a pre-defined role (e.g., "Taxation Team"), so that new employees can access the system securely.
- define and modify the permissions for each user role, so that I can enforce the principle of least privilege across the application.
- view a detailed audit log of user activities, so that I can investigate any security incidents.
- As a Compliance Manager,  They want to:
- trigger a password reset for a client who is locked out of their portal, so that I can provide immediate assistance.

## Module 11- External System Integration Module(Phase 1)

- As a System Admin, They want to:
- configure the API connection to our company website's contact form, so that all new leads are automatically captured in the Filing Buddy sales pipeline.
